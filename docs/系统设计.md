# 系统设计说明

项目：拾联通讯录；成员：832401315 孙梓焜、832401318 肖正宇。

## 结构
浏览器 HTML/CSS/JavaScript → HTTP JSON 接口 → Python 服务 → SQLite 数据库。Excel 使用 openpyxl 处理。无需前端构建，适合课程环境快速复现。

## 数据模型
contacts 表包含整数主键 id 与 JSON 文本 data。data 包含 name、phones、emails、social、addresses、notes、favorite。每种联系方式在文本中按换行保存，支持同一人多个联系方式。姓名必填，其余字段可空。此模型便于演示；大型系统应进一步将联系方式拆为子表。

## 接口
| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/contacts | 查询全部联系人 |
| POST | /api/contacts | 新增；携带 id 则更新 |
| DELETE | /api/contacts/{id} | 删除 |
| GET | /api/export | 下载 Excel |
| POST | /api/import | 以二进制正文上传 Excel |

搜索与收藏筛选在浏览器执行。导入先验证整个文件，再在同一事务中插入，避免部分成功。导出强制文本类型，避免备注中的公式字符串被 Excel 执行。用户文本通过 textContent 显示，SQL 采用参数绑定。

## 已解决的实际问题
Windows 验收时发现数据库连接未及时关闭，导致临时测试数据库无法清理。现使用 closing 包装连接，并显式管理事务，重新运行集成测试通过。

## 限制
本地单用户应用，无登录、权限及多用户隔离；不应直接开放公网。导入采用追加策略，不自动去重。电话请在 Excel 内设为文本以保留前导零。
