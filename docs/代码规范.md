# 代码规范与协作约定

Python 使用四空格缩进，函数使用 snake_case；JavaScript 使用有意义的变量名。界面渲染用户输入使用 textContent，SQL 使用参数绑定。Excel 导入先完成校验再整体写入；导出文本避免被解释为公式。

两人编码前商定模块边界，建议分别负责后端与 Excel、前端与交互，并交叉评审。每个可审查的实际改动单独提交，提交信息说明目的。功能分支通过 Pull Request 合并。不得补造他人提交或虚构工时。

手动验收：新增含多行联系方式的联系人；刷新确认保留；编辑收藏并筛选；搜索联系方式；导出再导入，核对内容；导入缺姓名的文件，确认未部分写入；删除测试联系人。
