# 拾联 · 通讯录

## 运行
安装 Python 3.10 或更高版本，在本目录执行：

    python -m pip install -r requirements.txt
    python app.py

浏览器打开 http://127.0.0.1:8000 。停止服务按 Ctrl+C。

支持联系人新增、编辑、删除、搜索、收藏筛选；每个联系人支持多行电话、邮箱、社交账号和地址。数据保存在 contacts.db，重启后保留。

## Excel
先点击“导出 Excel”获得模板。保留七列表头：姓名、电话、邮箱、社交账号、地址、备注、收藏。多种联系方式在同一单元格内换行；收藏填“是”或“否”。姓名必填。导入为新增，不覆盖现有联系人；重复导入会新增重复记录。错误文件整批回滚。限制 5MB、10000 条。
